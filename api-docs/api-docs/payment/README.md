# Billing, Razorpay Payments & Account Centre Module — API Documentation

## 📍 Base URL
- **Primary Mobile / Web Prefix:** `http://localhost:8000/v1`
- **Legacy Payment REST Prefix:** `http://localhost:8000/api/payments`

---

## 🎯 Overview & Architecture

The Billing, Payments & Account Centre module provides complete monetization, subscription lifecycle management, Razorpay payment gateway integration, cryptographic signature verification, boost allowances, communication preferences, and DPDP Act / GDPR policy consent tracking.

### Core Payment & Entitlement Architecture:
1. **Plans & Entitlements:**
   - **`Free`**: Standard discovery feed, basic matching, and structured date planning.
   - **`Plus`** (₹1,999 / $19.99 monthly): Unlimited matches, priority candidate exposure, and full cultural filters.
   - **`Premium`** (₹3,999 / $39.99 monthly): Full AI Profile Assistant, unlimited chat & audio/video calling, and priority support.
2. **Razorpay Checkout Flow:**
   - `POST /v1/billing/checkout` resolves the target plan, initiates an order with Razorpay, and creates an `UNPAID` subscription record in PostgreSQL.
   - Frontend invokes the Razorpay SDK (Checkout.js or Flutter Razorpay plugin) using the returned `keyId`, `orderId`, and `amountMinor`.
   - On payment success, frontend submits payment parameters (`razorpay_payment_id`, `razorpay_order_id`, `razorpay_signature`) to `POST /v1/billing/verify`.
   - Backend cryptographically verifies the HMAC SHA-256 signature against `RAZORPAY_KEY_SECRET`, activates the subscription (`status: "ACTIVE"`), and generates a durable payment receipt.
3. **Account Centre Governance:**
   - Members can configure multi-channel quiet hours (`channels: { email, push, sms, inApp }`).
   - Members record explicit consent for published Terms of Service and sensitive cultural matching policies.

### 2. Initiate Razorpay Checkout Order
**`POST /v1/billing/checkout`**

- **Full URL:** `http://localhost:8000/v1/billing/checkout`
- **Auth Guard:** Bearer Access Token (`member`)

#### Request Body
```json
{
  "planId": "plus",
  "billingCycle": "monthly"
}
```

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `planId` | String | Yes | Plan identifier: `"plus"` or `"premium"`. |
| `billingCycle` | String | No | Billing cycle: `"monthly"` or `"annual"` (default: `"monthly"`). |

#### Response (`200 OK`)
```json
{
  "success": true,
  "keyId": "rzp_test_1DP5mmOlF5G5ag",
  "orderId": "order_O123456789",
  "gatewaySubscriptionId": "order_O123456789",
  "subscriptionId": "cm8sub001xyz",
  "amountMinor": 199900,
  "currency": "INR",
  "planName": "Plus"
}
```

### 3. Verify Razorpay Payment Signature
**`POST /v1/billing/verify`**

- **Full URL:** `http://localhost:8000/v1/billing/verify`
- **Auth Guard:** Bearer Access Token (`member`)

#### Request Body
```json
{
  "razorpay_payment_id": "pay_O123456789",
  "razorpay_order_id": "order_O123456789",
  "razorpay_signature": "9ef2bc384b1d6f1a8c3d7e5b2...",
  "subscriptionId": "cm8sub001xyz"
}
```

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `razorpay_payment_id` | String | Yes | Payment identifier returned by Razorpay Checkout. |
| `razorpay_order_id` | String | Yes | Order identifier returned by Razorpay Checkout. |
| `razorpay_signature` | String | Yes | Cryptographic HMAC SHA-256 signature generated by Razorpay. |
| `subscriptionId` | String | No | Subscription ID returned from the checkout step. |

#### Response (`200 OK`)
```json
{
  "success": true,
  "verified": true,
  "planId": "plus"
}
```

#### Error Responses
- `400 Bad Request`: Missing payment details or invalid cryptographic HMAC signature.

### 9. Record Policy Consent
**`POST /v1/account-centre/consent`**

- **Full URL:** `http://localhost:8000/v1/account-centre/consent`
- **Auth Guard:** Bearer Access Token (`member`)

#### Request Body
```json
{
  "id": "sensitive",
  "version": 1,
  "accepted": true
}
```

| Field | Type | Required | Description |
| :--- | :--- | :--- | :--- |
| `id` | String | Yes | Policy ID: `"terms"` or `"sensitive"`. |
| `version` | Integer | Yes | Version number of the policy accepted. |
| `accepted` | Boolean | Yes | True to accept, false to withdraw consent. |

#### Response (`200 OK`)
```json
{
  "saved": true
}
```
